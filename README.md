Halyard is designed to route consented voice jobs through a rigorous multi-objective pipeline: **Quality, then Consent, then Latency, then Cost.**

Welcome to Halyard—a modern, robust web application built with a cutting-edge full-stack architecture, featuring automated tooling, seamless authentication workflows, and interactive studio capabilities.
🚀 Overview
Halyard is designed for performance and reliability, integrating advanced client-side routing, secure database migrations, and a comprehensive build and preview pipeline.
Key Features
* Advanced Authentication & Isolation: Prewired and secure auth middleware, sign-in gates, and pglite dialect support.
* Modular Studio & Previewer: Interactive studio components coupled with real-time host bridges and preview origin management.
* Robust Tooling & Scripts: Automated brand checks, atomic write mechanisms, migration plans, and browser smoke tests.
* PWA & Offline Support: Integrated Progressive Web App plugins and asset management for seamless deployment.
📦 Project Structure
halyard/
├── server/          # Server-side middleware, virtual identity, and backend logic
├── migrations/      # Database authentication and schema migrations
├── public/          # Static assets, favicons, open graph images, and PWA manifests
├── scripts/         # Automated build, test, migration, and smoke-test utilities
├── src/             # Core application routes, components, and state management
└── screenshots/     # Visual documentation and build previews

🛠️ Getting Started
Prerequisites
Ensure you have the following installed on your system:
* Node.js (Active LTS recommended)
* npm or pnpm / yarn
Installation & Development
1. Clone the repository:
git clone https://github.com/ljrseals-dev/didactic-bassoon.git
cd didactic-bassoon/halyard

2. Install dependencies:
npm install

3. Run the startup script or development server:
bash startup.sh

🧪 Testing & Quality Assurance
Halyard includes a thorough test suite covering migrations, atomic file writes, brand conformity, and authentication invariants. Run tests using:
npm test
